# 📋 Student Management System — Project Plan

## 1. Project Overview
**Project Name:** Allen Sheen Student Management System
**Version:** 1.0
**Author:** Allen Sheen
**Tech Stack:** HTML, CSS, JavaScript, Supabase

**Description:** A simple web-based system to store, view, add, edit, and delete student records. Built for school/classroom use with secure database storage via Supabase.

---

## 2. Objectives
- ✅ Create a clean, user-friendly interface
- ✅ Store student data securely in a cloud database
- ✅ Perform basic CRUD operations (Create, Read, Update, Delete)
- ✅ Make the system responsive — works on desktop and mobile
- ✅ Keep code organized and easy to maintain

---

## 3. Features
| # | Feature | Status |
|---|---------|--------|
| 1 | Add new student (Name, ID, Course, Year Level, Email, Contact) | ✅ Planned |
| 2 | View / list all students | ✅ Planned |
| 3 | Search student by name or ID | ✅ Planned |
| 4 | Edit student information | ✅ Planned |
| 5 | Delete student record | ✅ Planned |
| 6 | Data validation (required fields, valid format) | ✅ Planned |
| 7 | Loading states & success/error messages | ✅ Planned |
