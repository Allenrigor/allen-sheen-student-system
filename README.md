# Student Records System

A simple web-based student records management system built as a class demonstration project.

> **⚠️ Fictional records only — for demonstration purposes only.**

## 📌 About
This project demonstrates basic user authentication and record management using:
- **HTML5** — Structure and markup
- **JavaScript** — Client-side interactivity
- **Supabase** — Backend and user authentication
- **Vercel** — Deployment and hosting

## ✨ Features
- Operator registration & sign-in
- Protected student records view
- Sign-out functionality

## 🔧 Setup & Configuration
Environment variables (see `.env.example`):
- `VITE_SUPABASE_URL` — Your Supabase project URL
- `VITE_SUPABASE_ANON_KEY` — Your public Supabase anonymous key

## ⚠️ Important Notes
- This is a **class demonstration** — contains fictional/example data only
- **Never upload real student information, passwords, or secret keys** to this repository
- Keep `.env` and credentials private — they are excluded via `.gitignore`
